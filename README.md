# Aulas de Programação Orientada a Objetos (POO)

Este repositório foi criado para armazenar e organizar todos os códigos, exemplos e exercícios práticos desenvolvidos durante as aulas de **Programação Orientada a Objetos (POO)** utilizando a linguagem Java.

O foco principal é consolidar os pilares da POO e aprender a escrever códigos mais limpos, estruturados, reutilizáveis e fáceis de manter.

---

## Conceitos Estudados

Até o momento, o repositório cobre os seguintes conceitos fundamentais do paradigma orientado a objetos:

* **Classes e Objetos:** A estrutura base (molde) e a instanciação dos objetos na memória.
* **Atributos e Métodos:** As características e os comportamentos que um objeto possui (como o método `acelerar()`).
* **Métodos Construtores:** Inicialização correta dos objetos no momento em que são criados.
* **Encapsulamento:** Proteção de dados sensíveis utilizando modificadores de acesso (`private`), controlando a leitura e escrita através de métodos **Getters e Setters**.
* **Sobrecarga de Métodos (Polimorfismo Estático):** Criação de métodos com o mesmo nome, mas que se comportam de forma diferente dependendo dos parâmetros recebidos.
